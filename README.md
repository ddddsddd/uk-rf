# Камень, ножницы, УК РФ

Браузерная 3D-игра «камень-ножницы-бумага», где вместо камня и ножниц — статьи Уголовного кодекса.
10 статей, до 3 игроков за одним столом, свободные места можно занять ботами.

Зал суда с фиксированной камерой: стол с кожаной вставкой, лампа, судейский молоток, наручники,
папки дел, тень от тюремной решётки. Шейдеры: голографическая фольга на картах, сгорание
проигравшей карты, лучи ударов, ударные волны, дым и полицейские мигалки на фоне, пыль в луче света,
постобработка (bloom, хроматическая аберрация, зерно, виньетка). Все текстуры и звуки генерируются
кодом, внешних картинок и аудиофайлов нет.

## Правила

Все игроки одновременно выбирают статью. Статьи стоят по кругу:

`290 → 159 → 158 → 228 → 264.1 → 105 → 115 → 213 → 162 → 272 → (снова 290)`

Каждая статья **бьёт 4 следующие**, **проигрывает 4 предыдущим** и сыгрывает **вничью с противоположной**
(через 5 позиций). Так у любой карты ровно 4 победы, 4 поражения и 1 ничья — баланс как в обычном RPS.

За каждую побеждённую статью соперника дают 1 очко (втроём за раунд можно взять до 2 очков).
Играют до 3/5/7/10 очков. При равенстве лидеров назначается дополнительное заседание.

| Статья | Карта | Бьёт |
|---|---|---|
| 290 | Взятка «Конверт» | 159, 158, 228, 264.1 |
| 159 | Мошенничество «Схема» | 158, 228, 264.1, 105 |
| 158 | Кража «Карманник» | 228, 264.1, 105, 115 |
| 228 | Наркотики «Народная» | 264.1, 105, 115, 213 |
| 264.1 | Пьяный за рулём «Под градусом» | 105, 115, 213, 162 |
| 105 | Убийство «Мокруха» | 115, 213, 162, 272 |

У каждой из 40 побед и 5 ничьих есть своя подпись («Зачем красть, если можно просто „занести“?»).

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm start            # http://localhost:3000
```

### Поделиться ссылкой с друзьями (без регистрации)

```bash
npm run share
```

Скрипт запускает сервер и открывает бесплатный публичный туннель (сначала tunnelmole, затем
Cloudflare quick tunnel), после чего печатает ссылку вида `https://xxxx.tunnelmole.net`.
Ссылка работает, пока открыто окно терминала. Там же печатается адрес для игры в одной Wi-Fi сети.

### Постоянный хостинг

- **Render (бесплатно):** залейте папку в репозиторий GitHub → на render.com `New → Blueprint` →
  выберите репозиторий (используется `render.yaml`). Получите постоянный адрес `https://uk-rps.onrender.com`.
  Бесплатный сервис засыпает после 15 минут простоя и просыпается примерно за минуту.
- **Docker / VPS:** `docker build -t uk-rps . && docker run -p 3000:3000 uk-rps`.

Порт задаётся переменной `PORT` (по умолчанию 3000).

## Управление

- Мышь: наведите на карту, чтобы увидеть, кого она бьёт, и кликните, чтобы выбрать.
- Телефон: коснитесь карты (появится подсказка), коснитесь ещё раз, чтобы выбрать.
- Клавиши `1`–`9`, `0` — быстрый выбор карты.
- 💬 — реакции, 📖 — кодекс (таблица «кто кого бьёт»), 🔊 — звук.

Параметры адреса: `?q=low` — облегчённая графика для слабых устройств, `?q=high` — максимум эффектов
без автоснижения качества, `?transport=poll` — принудительно HTTP long-polling вместо WebSocket.

## Как устроено

- `server.js` — HTTP-сервер, раздача статики, комнаты до 3 игроков, боты, таймер хода (30 с),
  подсчёт очков. Транспорт: WebSocket (`/ws`) и запасной HTTP long-polling (`/api/*`) для туннелей
  и прокси без поддержки WebSocket. Переподключение без потери места (по токену в localStorage).
- `public/shared/rules.js` — статьи, круг побед и подписи (общие для сервера и клиента).
- `public/js/scene.js` — сцена Three.js, шейдеры и анимации.
- `public/js/textures.js` — процедурные текстуры на canvas.
- `public/js/audio.js` — синтезированные звуки (WebAudio).
- `public/js/main.js` — интерфейс, лобби, HUD, вердикты, кодекс.
- `share.js` — запуск сервера с публичным туннелем.

Игра — шутка. Сроки указаны упрощённо (максимум по ч. 1 статьи) и не являются юридической
консультацией. Не нарушайте закон.
